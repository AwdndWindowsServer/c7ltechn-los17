# 02 · 刷机与排障

## 0. 准备

```bash
# 备份（有 root / TWRP 时）
dd if=/dev/block/bootdevice/by-name/efs       of=/sdcard/efs.img
dd if=/dev/block/bootdevice/by-name/modemst1  of=/sdcard/modemst1.img
dd if=/dev/block/bootdevice/by-name/modemst2  of=/sdcard/modemst2.img
dd if=/dev/block/bootdevice/by-name/persist  of=/sdcard/persist.img
```

C7 分区（PIT）：`BOOT 32 MiB`、`RECOVERY 32 MiB`、`SYSTEM 3.52 GiB`、`CACHE 200 MiB`、
`PERSIST 32 MiB`、`MODEM 96 MiB`、`APNHLOS 32 MiB`、`DSP 16 MiB`、`EFS 16 MiB`。

## 1. Odin / 搞机助手（AP 槽）

1. 关机 → **电源 + Home + 音量减** → 音量加确认 → 屏幕出现绿色下载图标。
2. 连电脑，工具识别到 `COM` 端口。
3. **AP** 选 `c7ltechn-port-odin-<date>.tar.md5`；`BL`/`CP`/`CSC`/`USERDATA` 全部留空。
4. 只勾 `Auto Reboot` + `F.Reset Time`，Start。

> 首次从原厂系统过来，建议先刷一次 TWRP 并**格式化 data**，否则旧的加密/art 缓存会导致卡开机。

## 2. TWRP 卡刷

1. TWRP → 安装 → 选 `lineage-17.1-*-c7ltechn-port-kernel*.zip`。
2. 刷完 **清除 → 格式化 Data 分区**（输入 yes）。
3. 重启系统。首启 3~10 分钟。

## 3. 首启判断

| 阶段 | 正常表现 | 异常处理 |
| --- | --- | --- |
| bootloader | 三星 logo + `Set Warranty Bit : kernel` | 卡住 → dt 区/内核不对 |
| 内核 | 屏幕背光短暂变化、logo 后出现 Lineage 动画 | 黑屏重启 → 面板驱动或 DTB 不对 |
| Android | 动画 3~10 分钟后进设置向导 | 动画超过 12 分钟 → 抓 logcat |

抓日志（Linux/macOS，装了 adb）：

```bash
adb devices
adb logcat -b all -d > logcat.txt
adb shell dmesg > dmesg.txt
adb shell cat /proc/last_kmsg > last_kmsg.txt   # 上次崩溃时最有用
```

## 4. 常见问题

**卡在三星 logo 后重启**
内核没起来。用 TWRP 挂载 boot 分区后 `cat /proc/device-tree/model` 应是 `Samsung Galaxy C7`；
若还是 `Xiaomi Redmi Note 4`，说明 dt 区还是 donor 的 → 重新打包时确认 `km/dtb` 存在。

**触摸没反应**
`dmesg | grep -i -E 'melfas|mms449|i2c_7'`；C7 触摸在 i2c_7 地址 0x48，需要 MMS449 驱动和正确的中断/复位 GPIO。

**Wi-Fi 打不开**
`dmesg | grep -i wcn`；需要 `wlan/prima/WCNSS_qcom_wlan_nv.bin`、`wlan_mac.bin`
（`C7_BLOBS=1` 时从 vendor 包取），以及 `qcom_wcnss_pil` 固件加载。

**无声音**
`dmesg | grep -i rt5659`，`tinymix` 看通路；C7 是 RT5659 codec + TFA9897 smartamp。

**无信号 / 双卡异常**
首版沿用 donor 的 RIL；`C7_BLOBS=1` 会覆盖 `rild`/`libsec-ril*`。仍不行则需按 C7 的
`/vendor/etc/init/*.rc` 与 `android.hardware.radio` 版本对齐。

## 5. 回退

Odin 刷三星官方固件的 `AP + BL + CP + CSC`（**不要** HOME_CSC，会保留数据导致冲突）。
本移植不动 bootloader，所以下载模式永远进得去。
